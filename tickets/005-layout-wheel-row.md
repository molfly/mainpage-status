# 005. Вёрстка: колесо по центру вьюпорта, меню в ряд

Статус: done
Дата: 2026-09-17

## Проблема

При появлении раздела «Меню» колесо прижималось к верхнему краю: `.page__center`
с `flex: 1` не получал лишнего пространства, когда контент страницы превышал
вьюпорт. Меню шли одно под другим.

## Решение

- `.page__center` — `min-height: 100vh` (`100svh` для мобильных): колесо
  центрируется в первом экране; при скролле к меню уходит вверх естественно.
- Меню: места в один ряд — `.menus__row` (`repeat(auto-fit, minmax(280px, 1fr))`),
  на узком экране переносятся. Место = колонка (название + сетка фото).
