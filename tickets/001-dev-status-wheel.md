# 001. Dev-версия: колесо статусов

Статус: done
Дата: 2026-09-17

## Задача

Dev-версия статус-страницы: по центру экрана — колесо выбора статуса в стиле числового пикера macOS.
Статусы: «из дома», «в офисе», «в отпуске». Дизайн — по DESIGN.md.

## Результат

- `site/index.html` — самодостаточная страница (HTML + CSS + JS, без сборки и зависимостей).
- Колесо: бесконечная прокрутка трёх статусов, центральный элемент — выбранный статус.
- Ввод: колесо мыши/трекпада, drag с инерцией, клик по пункту, стрелки ↑/↓ на клавиатуре.
- Readout под колесом показывает выбранный статус (`aria-live`).

## Дизайн (по DESIGN.md)

- Семантические токены (`--bg`, `--text`, `--border`, `--accent`), системная типографика.
- Затухание краёв — через CSS-маску; центр отмечен парой hairline-границ.
- Тёмная тема через `prefers-color-scheme`; `prefers-reduced-motion` отключает анимации.
- Доступность: `listbox`/`option`, `aria-activedescendant`, видимый фокус, состояние не только цветом.

## Что дальше

- Сохранение выбранного статуса (хранилище/бэкенд).
- Автоматический статус по расписанию.
- Публикация (GitHub Pages из `site/`).
