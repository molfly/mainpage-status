# 002. Статус меняет только владелец

Статус: open (механизм не выбран)
Дата: 2026-09-17

## Решение

Устанавливать статус может только владелец (molfly). Публичная страница — только отображение.

## Варианты механизма (не выбран)

1. **Секретная ссылка / токен в URL** — просто, но ссылку видно в истории и реферах.
2. **GitHub OAuth + проверка логина == molfly** — надёжно, но Pages статический,
   потребуется слой на Actions/Functions.
3. **Правка через git** (коммит в `data/status.json`) — авторизация через GitHub,
   простейший вариант без бэкенда.

## Заметки

- Dev-версия (`site/index.html`) ограничений не имеет: колесо меняет статус
  локально, без сохранения.
- Выбор механизма определит способ хранения статуса (см. 001 «Что дальше»).
